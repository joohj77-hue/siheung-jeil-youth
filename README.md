# 시흥제일 청소년교회 웹사이트 (Siheung-Jeil Youth Church)

시흥제일교회 청소년교회(중·고등부) 학생, 학부모, 교사를 위한 공식 웹사이트입니다.

---

## 📌 주요 기능 명세

1. **메인 화면 (`/`)**
   - 비전 및 슬로건 배너
   - 담당 교역자 소개 카드 (사진 및 목회 메시지)
   - 이번 주 예배 요약 (시간, 장소, 설교 본문, 섬김이 요약)
   - 최신 유튜브 설교 영상 플레이어 및 공식 인스타그램 바로가기
   - 네이버 지도 연동 예배장소 안내 (원클릭 주소 복사 & 길찾기 앱 연결)

2. **예배 & 말씀 (`/worship`)**
   - **예배위원 탭**: 인도자, 대표기도, 사회자, 찬양팀, 예배 담당 반 (안전 원칙에 따라 방송팀 제외)
   - **찬양 콘티 탭**: 주차별 찬양 곡 순서, 곡목, 가사 요약, 유튜브 링크, 악보 링크
   - **설교 요약 탭**: 설교 날짜, 본문, 핵심 묵상 요약, 유튜브 영상 및 지난 설교 아카이브

3. **통합 달력 (`/calendar`)**
   - **통합 캘린더**: 교회 행사(초록 뱃지)와 학교 학사일정/방학(파랑 뱃지) 구분 제공
   - **월별 학생 생일 안내**: 안전 원칙을 철저히 준수하여 성함 마스킹 적용 (`김*우`, `이*진`)

4. **소통 게시판 (`/board`)**
   - **공지사항**: 카드뉴스 및 주요 공지 목록과 상세 팝업
   - **기도제목 & 고민상담**: 4자리 PIN 비밀번호 잠금 비밀글 지원, 교역자/교사 답글 렌더링

5. **교사 전용 포털 (`/teachers`)**
   - 교사 비밀번호 인증 (`youth` 또는 `1234`)
   - 구글 스프레드시트 엑셀 출석부 원클릭 이동 버튼 제공

---

## 🛡️ 교회학교 안전 및 개인정보 보호 원칙
- **학생 실명 비공개**: 생일자 목록 표기 시 반드시 `maskStudentName()`을 거쳐 `김*우` 형태로 노출됩니다.
- **학생 연락처/사진 비공개**: 학생의 전화번호, 집 주소, 얼굴 사진 등 개인 식별 정보는 게시하지 않습니다.
- **비밀글 암호화**: 학생들의 고민상담 및 개인 기도제목은 4자리 핀번호 설정으로 보호됩니다.

---

## 🛠️ 기술 스택
- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS (Deep Green `#0F4C3A` & Deep Blue 포인트)
- **Icons**: Lucide React
- **Deployment**: Vercel (무료 웹 호스팅)

---

## 📂 데이터 간편 수정 방법 (`src/data/`)

별도의 데이터베이스(DB) 지식 없이도 교역자나 교사가 텍스트 파일만 수정하여 웹사이트 콘텐츠를 즉시 갱신할 수 있습니다.

- `src/data/pastor.ts`: 담당 교역자 사진, 성함, 한 줄 메시지, 교회 기본 정보
- `src/data/worship.ts`: 이번 주 주일 예배 정보, 예배위원 명단, 찬양 콘티 곡 목록, 설교 요약
- `src/data/calendar.ts`: 교회 행사 일정, 학교 시험/방학 학사일정, 월별 학생 생일자 명단
- `src/data/notices.ts`: 주일 공지사항 카드뉴스
- `src/app/teachers/page.tsx`: 교사 접근 비밀번호 및 구글 스프레드시트 출석부 URL 링크

## 🚀 로컬 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저에서 http://localhost:3000 접속
```

## 🌐 Vercel 무료 배포 가이드
1. [GitHub](https://github.com)에 이 저장소를 업로드(Push)합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **Add New Project**를 선택합니다.
3. 방금 업로드한 저장소를 선택하고 **Deploy** 버튼을 누르면 1분 내로 무료 웹사이트 주소(`https://xxx.vercel.app`)가 생성됩니다.
